# Biryani & Fry – Restaurant Website

A modern React single-page site for a biryani and fry restaurant with menu, Google Map location, and a bulk delivery enquiry form.

## Tech
- React + Vite
- Responsive CSS (no framework) with glassmorphism and subtle animations

## Scripts

```bash
# Install deps
npm install

# Start dev server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```

## Configure
- Update the address text and coordinates in `src/components/Location.jsx` if needed.
- Set your restaurant email in `src/components/EnquiryForm.jsx` (replace `orders@yourrestaurant.com`).

## Notes
- The UI/UX styling is inspired by the visual feel of `https://cornrevolution.resn.global/#science` (dark, futuristic gradients, soft glass UI).
- Google Maps is embedded via iframe for simplicity; replace with Maps JS SDK if you need more control.
